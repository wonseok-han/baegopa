## 1. 기능 개요

"배고파, 뭐 먹지?" — 사용자의 현재 위치 기반으로 반경 내 음식점을 검색하고, 다양한 미니게임을 통해 음식점/메뉴를 랜덤 선택해주는 웹앱.

### 핵심 플로우

```
[위치 수집] → [반경 설정] → [음식점 검색] → [게임 선택] → [미니게임 플레이] → [결과 표시]
```

## 3. 기능 범위 (Scope)

### In-Scope (MVP)

| # | 기능 | 설명 |
|---|------|------|
| 1 | 위치 수집 | Browser Geolocation API로 현재 위치 획득 |
| 2 | 반경 설정 | 500m / 1km / 2km 선택 |
| 3 | 음식점 검색 | 외부 API(Google Places 또는 Kakao)로 주변 음식점 조회 |
| 4 | 게임 선택 | 미니게임 목록에서 선택 or 랜덤 배정 |
| 5 | 미니게임 — 룰렛 | 회전판 돌리기 (CSS animation) |
| 6 | 미니게임 — 슬롯머신 | 3릴 슬롯 (Framer Motion) |
| 7 | 결과 표시 | 선택된 음식점 정보 (이름, 카테고리, 거리, 지도 링크) |
| 8 | 다시하기 | 결과 불만족 시 재게임 |

### Out-of-Scope (향후)

- 핀볼, 뽑기, 사다리타기 (추가 미니게임)
- 사용자 인증/회원가입
- 방문 기록/히스토리 저장
- 음식점 리뷰/평점 자체 제공
- 메뉴 추천 (음식점 단위만 MVP)

## 4. 기술 결정 사항

| 결정 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | Next.js 15 (App Router) | SSR 불필요하지만 API Routes 프록시 필요 |
| 스타일링 | Tailwind CSS 4 | 빠른 프로토타이핑, 유틸리티 퍼스트 |
| 애니메이션 | Framer Motion | 게임 연출 + 페이지 전환 |
| 음식점 API | Google Places API (1차) | 글로벌 커버리지, Nearby Search |
| 상태관리 | useState/useReducer | 단순 앱, 외부 라이브러리 불필요 |
| 배포 | Vercel | 무료, Next.js 최적화 |

### API 호출 전략

```
Client → /api/places (Next.js Route Handler) → Google Places API
```

- API Key 서버 사이드 보호
- Rate limit은 Vercel Edge에서 자연 제한 (무료 플랜 기준 충분)
