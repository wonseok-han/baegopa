## v0.2.0 - 2026-10-07

음식 종류 선택부터 핀볼 경주까지 흐름을 개선하고, 마블런 단일 게임과 검색 API 안정성을 강화한 릴리즈. 릴리즈 준비 변경 전 main 대비 43 files changed, +3,031 / -2,168 lines.

### Added

- **음식 종류별 후보 선택** — PR #6
  - 한식 · 일식 · 중식 · 양식 · 아시아음식 · 분식 · 치킨 · 패스트푸드 · 기타 분류 제공
  - Kakao의 전체 카테고리 경로로 분류하고, 선택한 종류의 음식점 후보와 개수 표시
  - 후보가 없을 때 종류·반경 변경 안내, 한 곳만 있어도 결과 확인 가능

- **핀볼 경주와 접근성** — PR #6
  - 후보마다 구슬 하나를 배정하고, 가게별 번호·색상 및 선두 음식점 표시
  - 고정된 후보와 동일한 물리 계산을 사용해 건너뛰어도 같은 결과 유지
  - 움직임 줄이기 설정, 움직임 없는 결과 확인, 기본 꺼짐인 선택형 사운드 제공

### Changed

- **마블런 단일 게임에 집중**
  - 룰렛·슬롯머신·뽑기 및 게임 선택 UI 제거
  - 음식 종류 → 위치·후보 확인 → 핀볼 → 결과 흐름으로 홈·게임·결과 화면 정비

- **핀볼 물성과 진행 속도 개선** — PR #6
  - 3배속 재생을 실제 시간 기준으로 변경하고 초당 120회 충돌 계산 적용
  - 장애물 재질·반발력, 엇갈린 경사판, 옆 범퍼, 회전봉의 접촉 속도 보정
  - 24초 내 미완주 시 선두 선택을 명시하고, 물리 코스의 동등한 당첨 확률은 보장하지 않음

- **검색 API 및 개발 검증 정비**
  - 좌표·반경·검색어·페이지 검증, IP 기반 요청 제한, Kakao 호출 타임아웃 추가
  - 테스트를 포함하도록 `pnpm check` 확장
  - PR의 정확한 HEAD SHA를 검증하는 수동 CI와 실행 안내 추가 — PR #6

### Fixed

- 위치·반경 변경 및 화면 이탈 시 이전 검색을 취소해 오래된 응답이 최신 상태를 덮어쓰는 문제 방지
- 위치 초기화 뒤 늦게 도착한 GPS 응답과 저장 데이터 처리 보강
- 지도 SDK를 사용할 수 없어도 음식점 검색을 계속할 수 있도록 처리
- 결과 외부 링크를 허용된 Kakao 지도 URL로 제한
- 빠른 직선 낙하, 장애물 접촉·반발 및 백그라운드 복귀 시 경주 속도 문제 보정 — PR #6
